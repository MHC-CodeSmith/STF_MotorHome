# Aquisição e proveniência de material externo

`catalogo.csv` é **lista de candidatos**, não aprovação para cópia de código/CAD. Para baixar manualmente, use os URLs originários e registre em `registro_importacoes.csv`. Em particular:

- CAD Delica L400: página oferece `https://www.bradmitchellphoto.com/s/Delica-Conversion-CAD.zip` com FCStd/STEP/IGES/STL anunciados. A ferramenta de leitura de páginas não processa ZIP; não houve validação do conteúdo interno.
- Fiat Ducato L3H2: ficha indexada em 3D Warehouse; requisição automatizada retornou 403. Usar download via conta/interface e verificar o arquivo localmente.
- MELVING22: GitHub possui arquivos SolidWorks e IGS; veículo não é motorhome e faltava licença explícita.
- Stella Vita: referência de conceito, sem CAD público oficial verificado.

Na pasta por item, anotar em `externos/README.md` cada arquivo efetivamente integrado. Ver `docs/politica_fontes.md`.
