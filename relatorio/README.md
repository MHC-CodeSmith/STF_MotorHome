# Relatório final

Cada autor entrega sua seção já com memorial, equações, tabelas, gráficos, referências e link para script reproduzível. P6 faz montagem editorial, mas não corrige silenciosamente resultados de outro integrante. Use `bibliografia.bib` e controle de citações com padrão uniforme.

**Plano sugerido**: objetivo e tecnologias → especificações 1–16 → CAD/massa/dinâmica 17–24 → energia/autonomia 25–29 → simulações térmicas 30–35 → resumo dos resultados e limitações → anexos de código.
