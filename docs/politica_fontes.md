# Política de materiais prontos: o que pode reutilizar

1. **Página acessível não significa arquivo baixado**. Registrar separadamente `pagina_verificada` e `arquivo_validado`.
2. **Código aberto com licença**: integrar como dependência ou adaptar com cumprimento da licença e atribuição. Preferir API a cópia de bibliotecas inteiras.
3. **CAD/README públicos mas sem licença**: servir como referência e estudo; pedir autorização para redistribuir arquivos originais/adaptados; não presumir que 'grátis' é open-source.
4. **Teses e artigos**: citar equações, métodos e fatos com referência. Texto literal, figuras e tabelas estão sujeitos a direitos autorais. A existência de PDF não autoriza reproduzir páginas.
5. **Arquivos grandes e restritos**: guardar fora do Git até avaliar licença, então Git LFS para CAD/arquivos grandes quando permitido.
6. Para cada arquivo reaproveitado: cadastrar URL, nome/autor, licença, hash SHA256, commit/versão, data de acesso, modificação feita, item(s) de destino e reviewer.
7. **Resultados de terceiros não são resultados do cenário São Carlos**. Reexecutar tudo com as condições da disciplina.
