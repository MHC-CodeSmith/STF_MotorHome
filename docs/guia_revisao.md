# Checklist de aceitação para cada item

- [ ] Enunciado do item transcrito/resumido corretamente, com condições específicas preservadas.
- [ ] Cada entrada traz valor, unidade, condição, fonte e status provisório/final.
- [ ] Método e equações escritos com hipóteses e domínio de validade.
- [ ] Código executa de modo reproduzível com README de instalação/comando.
- [ ] Resultados em arquivo versionado + script gerador, não somente print.
- [ ] Gráficos apresentam eixos, unidades, legendas e fonte dos dados.
- [ ] Testes: dimensional, limite físico e comparação independente (quando aplicável).
- [ ] Item multidimensional: malha, condições de contorno, convergência e validação.
- [ ] Fontes citadas; cada reutilização externa com licença e histórico de adaptação.
- [ ] Impactos em outras áreas informados; revisão humana assinada/registrada.
